# Codemagic Assets.car Extractor

1. Upload all files in this ZIP to a GitHub repository.
2. Connect the repository to Codemagic.
3. Choose the `Extract Assets.car` workflow.
4. Start Build.
5. When finished, download `extracted_assets` from Artifacts.

Important files:
- `subscriptionLogo_report.txt`
- `asset_names.txt`
- any `subscriptionLogo*.png` files

`Assets.car` in this package was copied directly from the supplied original Tarab IPA.
